# nazafetch

A lightweight and stylish system information fetch tool for Linux.

```text
█▄░█ ▄▀█ ▀█ ▄▀█ █░█ █ █▀▄▀█ █▀▀
█░▀█ █▀█ █▄ █▀█ █▀█ █ █░▀░█ ██▄
```

`nazafetch` is a Bash system fetch with a custom true-color
violet-to-pink NAZAHIME logo.

## Features

- OS and architecture
- Linux kernel
- Desktop environment
- Package count
- Shell and terminal
- Window manager and session type
- GTK theme, icons and font
- CPU and GPU information
- Memory usage
- Disk usage
- Battery information
- True-color gradient logo

## Install

```bash
git clone https://github.com/nazahime/nazafetch.git
cd nazafetch
install -Dm755 nazafetch ~/.local/bin/nazafetch
```

Then run:

```bash
nazafetch
```

## Requirements

Linux, Bash and common GNU/Linux system utilities.

Currently developed and tested on Debian GNU/Linux 13 with GNOME.
